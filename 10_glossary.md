# Glosario

| Término | Qué significa |
|---|---|
| **ERP** | Sigla en inglés de "Planificación de Recursos Empresariales". Es un sistema que junta los procesos de una empresa en un solo lugar. |
| **Producto** | Lo que la empresa compra o vende. Tiene nombre, descripción y unidad de medida. |
| **Proveedor** | La empresa o persona a la que se le compran los productos. |
| **Orden de Compra** | El documento que se genera cuando se le pide mercancía a un proveedor. |
| **Recepción de Mercancía** | Cuando se registra que ya llegó lo que se pidió en una orden de compra, y se suma al inventario. |
| **Factura** | El documento que se le da al cliente cuando le vendemos algo. |
| **Cliente** | La persona o empresa a la que le vendemos y le facturamos. |
| **Stock / Inventario** | La cantidad que hay disponible de cada producto en un momento dado. |
| **Costo Promedio** | El precio promedio de un producto, calculado según lo que se ha pagado por él en distintas compras. |
| **Activo Fijo** | Las cosas de la empresa que duran tiempo (computadores, muebles, vehículos, etc.). |
| **Depreciación** | Cómo va perdiendo valor un activo fijo con el paso del tiempo. |
| **Nómina** | El pago que se le hace a un empleado, calculado según su salario y lo que pasó ese mes (faltas, horas extra, etc). |
| **EIS** | Módulo donde el gerente puede ver reportes e indicadores para tomar decisiones. |
| **SPA** | La aplicación web que corre en el navegador (Single Page Application). |
| **API** | La parte del sistema que tiene toda la lógica de negocio, y a la que la SPA le pide o le manda información. |
| **DIAN** | La entidad del gobierno colombiano ante la cual toca reportar las facturas electrónicas. |
